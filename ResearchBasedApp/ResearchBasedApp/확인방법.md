# 확인 방법

## 앱 기능 확인

배포 주소 <https://move-kit-data-transfer.db-1270.chatgpt.site>에서 아래 세 흐름을 확인합니다.

1. **보내기**: 테스트용 ZIP을 고르고 암호를 두 번 입력합니다. 전송 코드와 만료 안내가 표시되면 통과입니다.
2. **받기**: 다른 브라우저/기기에서 전송 코드와 암호를 입력합니다. SHA-256 일치 표시와 ZIP 저장 버튼이 나오면 통과입니다.
3. **오류 입력**: 잘못된 코드, 틀린 암호, ZIP이 아닌 파일을 각각 입력합니다. 설명 메시지가 표시되고 앱 화면이 계속 동작하면 통과입니다.

실제 개인정보·비밀값 대신 임의 테스트 파일을 사용합니다. ZIP은 20 MiB 이하로 준비합니다.

## 로컬 Worker 검증

프로젝트 루트에서 다음 명령을 실행합니다.

```bash
bash scripts/build.sh
node --check dist/server/index.js
node scripts/validate-artifact.mjs
node scripts/test-worker.mjs
```

빌드 성공, ESM 검사 통과, `Artifact is valid ESM...`, `Worker API checks passed...` 출력이 확인 기준입니다. Worker 테스트는 메모리 기반 임시 버킷을 사용합니다.
